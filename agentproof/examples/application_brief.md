# Application Brief

目标：申请一个评估 AI / Agent 实践能力的项目，需要提交“使用 Agent 或 AI 驱动构建的具体成果”和“使用证明与影响力证明”。

现状：申请人目前没有历史项目，也没有可公开的 GitHub 仓库或 token 账单截图。因此不能伪造历史记录，需要即时构建一个真实、可运行、可解释、可截图的项目，作为申请材料。

项目要求：
- 说明项目解决的核心痛点。
- 说明核心逻辑流，最好包含长链推理和多 Agent 协作。
- 产出 1200 字以内中文申请答案。
- 生成可上传的佐证材料列表。
- 生成运行日志、README、流程图截图和项目截图。

可用工具：
- Codex
- Claude Code
- GPT 系列
- DeepSeek 系列

申请策略：
- 不夸大不存在的 token 使用或账单。
- 用真实项目、真实文件、真实截图证明 AI 辅助交付能力。
- 如果后续有真实 API key，可运行 remote 模式生成更强的模型调用日志。
